# Contribuindo

As regras atuais de contribuição estão no arquivo canônico [`CONTRIBUTING.md`](../CONTRIBUTING.md) da raiz.

Antes de enviar uma alteração:

```bash
npm ci
npm run verify
```

Alterações no gerador, preview ou certificação devem incluir o E2E correspondente. Consulte também [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md), [`SECURITY.md`](../SECURITY.md) e [`SUPPORT.md`](../SUPPORT.md).
