# Suporte

## Dúvidas de uso

Consulte primeiro o `README.md`, `docs/SELF-HOSTING.md`, o guia de provedores e as issues existentes. Se a dúvida continuar, abra uma discussão no repositório com ambiente, objetivo e comandos executados.

## Erros reproduzíveis

Use o modelo “Relatar um erro”. Inclua versão ou commit, sistema operacional, versões de Node.js e npm, etapa afetada e reprodução mínima. Remova chaves, tokens, caminhos privados, prompts confidenciais e dados pessoais.

## Propostas

Use o modelo “Propor melhoria”. Explique o problema, o resultado esperado, os componentes existentes que podem ser reutilizados e critérios verificáveis de aceite.

## Segurança

Não abra issues públicas para vulnerabilidades. Siga `SECURITY.md` e use um GitHub Security Advisory privado.

## Limites

O projeto é mantido pela comunidade e não oferece SLA, suporte comercial implícito ou garantia de adequação a um domínio específico. A licença MIT e os gates automatizados não substituem a validação do operador sobre código, dados e infraestrutura.
